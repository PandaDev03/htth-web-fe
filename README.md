# HTTH Web Frontend

React + TypeScript base for the new HTTH web admin/client surface.

## Stack

- ReactJS + TypeScript + Vite
- TailwindCSS + Ant Design
- Redux Toolkit
- React Router
- TanStack Query

## Structure

- `src/app`: app providers, store, router setup
- `src/features`: feature-based modules
- `src/shared`: shared API client, components, config, types, utilities

## Commands

```bash
npm install
npm run dev
npm run build
```
